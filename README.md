# To My Dearest Soobin ♡

A responsive four-page fan site for TXT's Choi Soobin, built with plain HTML, CSS, and JavaScript. It includes a welcome page, a full love letter, a reasons page, and a photo gallery with a TXT playlist. The three supplied Soobin photos are stored locally in `assets/`.

Open `index.html` in a browser to preview. Google Fonts load when online and use system fallbacks offline. Playlist entries open YouTube Music search results and do not autoplay. The hug count is saved locally in the visitor's browser.

GitHub Pages deployment is configured through the workflow in `.github/workflows/pages.yml`.
