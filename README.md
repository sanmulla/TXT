# To My Dearest Soobin ♡

A four-page, responsive fan site for TXT's Choi Soobin, built with plain HTML, CSS, and JavaScript. Home, the letter, reasons, and gallery with music each have their own page, joined by previous/next page links. The three supplied Soobin photos are stored locally in `assets/`.

Open `index.html` in a browser to preview. Google Fonts load when online and use system fallbacks offline. Playlist entries open YouTube Music search results and do not autoplay. The hug count is saved locally in the visitor's browser.

GitHub Pages deployment is configured through `.github/workflows/pages.yml`.
