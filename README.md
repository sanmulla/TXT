# A Little Letterbook for Soobin ♡

A responsive six-page, full-screen letterbook for TXT's Choi Soobin. It uses a CSS envelope opening, animated paper turns, previous/next controls, floating hearts, and a closing sparkle animation. Only the current page is shown; the viewport does not scroll.

Open `index.html` to preview. The project uses plain HTML, CSS, and JavaScript. Google Fonts load online and fall back to system fonts offline. The supplied Soobin photos remain in `assets/` for future use.

GitHub Pages deploys the static site automatically through `.github/workflows/pages.yml`.
