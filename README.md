# A Little Letterbook for Soobin ♡

A responsive seven-page, full-screen letterbook for TXT's Choi Soobin. It opens with an animated envelope, turns through individual handwritten pages, includes an image-only photo album with click-to-enlarge images, and ends with a closing sparkle animation. Only the current page is shown and the viewport does not scroll.

Open `index.html` to preview. The project uses plain HTML, CSS, and JavaScript. Google Fonts load online and fall back to system fonts offline. An optional original ambient tone can be enabled or muted with the music button; it never starts automatically. The supplied Soobin photos are kept locally in `assets/`.

GitHub Pages deploys the static site automatically through `.github/workflows/pages.yml`.
